Android 端 demo（M4 前置 · 移动端唯一视觉/交互基准）

总体框架（2026-09-04 决议 v5）：无底部导航——会话页为基座（非 Fragment）；内容 = 底部宿主 Fragment（persistent bottom sheet）：会话底部常驻 peek 卡（书名+进度），点开展开近全高 sheet；sheet 内与桌面 GUI 同构：segTabs 四栏资料位（大纲/正文/人物/地点）、大纲 treeRow 树（引导线+双轴状态 chip+图例）、scene 叶/人物/地点点击下钻详情页（LeafPlanCard：事件序列/节奏拍/实体变更；profileHead+cardBlock 档案）；审批中心（角标）/ 书库 / 设置 / 设备管理 / 项目切换 / 登出经侧边抽屉（☰）。 设计基调 = 品牌皮 + Material 骨：四主题 token 与桌面端 app-redesign-demo.html 同源同值（宣纸白/墨夜/黛青/雪青）；组件形态遵循 Material 3（TopAppBar / BottomSheet / ModalDrawer / Snackbar），触控目标 ≥48px。

屏幕（6 + 覆盖层）

① 会话——打字机草稿面板（累计文本流）、工具行三态、运行状态三态（生成/审批挂起/失败重试）、三档执行模式、底部内容 peek 卡；② 内容 sheet（GUI 同构）——segTabs 四栏：大纲（treeRow 树+图例）/正文（摘要+卷·章树）/人物/地点（档案列表），scene 叶与档案行下钻详情页（LeafPlanCard 事件序列/节奏拍/实体变更；profileHead+cardBlock）；③ 审批中心——跨端 pending 列表；④ 书库——书单+解析状态（只读消费）；⑤ 设置——连接四态、设备管理、BYOK·Keystore、四主题；⑥ 登录/注册——单一表单 + deviceName + 成功态 用户名@server。 覆盖层：审批 BottomSheet（编辑·将被覆盖 / 新建·无既有数据 / 删除·将被删除；批准/驳回附意见、整批决策、120s 倒时自动拒绝）、通知（FGS 常驻 + 审批请求，shade 与锁屏）、崩溃恢复向导（续跑 / 先停在这里）、只读会话（他端持租约 + SSE 进度 + 接续 409）、断线降级、409 冲突。
