**Novel Harness** 是一个面向中文网文的 AI 创作工作台（harness）：一个 Electron 桌面应用，把「AI 写作」从聊天框里捞出来，变成一套有数据库、有审批、有记忆的正经创作流程。

> ⚠️ **当前是开发版**，正在快速迭代：界面、命令、配置随时会变。欢迎围观，暂不建议拿它存你的传世巨著（虽然数据库很稳）。

---

## 这不是又一个「AI 一键生成小说」的工具

市面上的套路是：一段 prompt，吐十万字，你自己都不想看第二眼。

这里的思路不一样——**创作是 AI 和人一起的事**。你不需要变成 prompt 工程师，也不需要替 AI 打字；你只管当一个有品味的作者：提要求、做决策、审草稿。AI 负责查资料、出方案、写初稿、改到满意。有人管这叫 vibe writing，我们觉得挺贴切：**你 review，AI 苦力。**

三件事撑起这个思路：

### 1. 数据库是唯一事实

模型会忘事、会编事，所以记忆不能靠它硬背。全书的人物、地点、大纲、正文全部存在 SQLite 里（每个项目一个独立的 `novel.db`）：

- **写前必查**：AI 动笔前先用只读工具查设定，不凭记忆臆造；
- **写时上锁**：写入走双层乐观锁，过期版本直接被拒，覆盖不了你的最新修改；
- **压完仍可查**：上下文自动压缩后，正文在数据库里仍有权威版本，AI 随时回查。

遗忘和幻觉治不了根，但治得了病程——靠查库，不靠背。

### 2. AI 永不未经审批污染正式稿

每个会话有三档模式：

| 模式 | 行为 |
| --- | --- |
| **review · 需审核**（默认） | AI 的所有写库操作按轮汇总成审批清单，你逐条批准 |
| **compose · 设计** | AI 只能写设计草稿（markdown），正式稿只读——大胆想，落笔必须过审 |
| **bypass · 直通** | 免审直接执行，适合信得过的琐碎操作（退出设计模式仍强制审批） |

拿不准的时候，AI 还会反过来用提问卡问你：「主线走复仇还是救赎？」——答案只在你手里。

### 3. 长会话不崩

写了三百章，上下文早爆了？三道门禁自动压缩（结构化骨架化 → 逐段摘要 → 硬丢弃）加一道超窗保险丝，任意长度的会话都不会因为窗口塞满而失败。反正正文都在库里，压缩丢不了事实。

## 它能做什么

**人机协作**

- 三模式会话（需审核 / 设计 / 直通），写作意图先审批、后落笔
- 按轮批量审批弹窗：左清单右详情，可全部批准、也可稍后处理
- 流内提问卡：AI 主动向作者提问、采集创意，阻塞等待你的答案
- 设计稿模式：完整状态机（设计 → 提交 → 应用 / 驳回 → 归档），每份草稿带哈希审计

**事实记忆**

- SQLite 存储（`node:sqlite`，零原生依赖）：大纲树、人物、地点、卷章、段落等 9 张表
- 23 个小说域读写工具：AI 直接读写正式稿，改完全部界面即时刷新（ZeroMQ 变更广播）
- `NOVEL.md` 全局约束（书名、世界观、基调、禁忌）：每次调用重新读取注入，AI 自己改完立即生效
- 正文中的实体引用一律走 `<character id>` 标签，未知标签直接剥离——不认识的 id 就是不存在

**工程化 harness**

- 1 会话 = 1 进程：崩溃后自动重派生、journal 重放、原地续跑
- subagent 委托：Explore（只读探索）/ Compose（草案创作）随叫随到
- Electron 主进程作为 Zygote：统一派生数据库与会话守护进程，API key 不出主进程
- 上下文压缩三道门禁 + 超窗保险丝（见上）

**模型与体验**

- 双适配器：Anthropic / OpenAI 兼容协议（DeepSeek 及一切兼容端点）
- 思考档位五档可调，流式输出（含思考流），凭据经系统 safeStorage 加密
- 多项目 workspace 隔离、四款主题（宣纸白 / 墨夜 / 黛青 / 雪青）、全键盘操作

## 快速开始

前置：Node ≥ 22，pnpm（`corepack enable` 即可）。

```bash
pnpm install      # 安装依赖
pnpm build        # 构建 core → ui → gui
pnpm gui:release  # 启动桌面应用
pnpm gui:debug    # 同上，verbose 日志 + 调试模式
```

模型配置二选一：

- 应用内 **设置 → Model Provider**（推荐）：支持多 profile，凭据加密存储；
- 环境变量：`NOVEL_PROVIDER_TYPE`（`openai` / `anthropic`）、`NOVEL_PROVIDER_BASE_URL`、`NOVEL_PROVIDER_API_KEY`、`NOVEL_PROVIDER_MODEL`。

目前没有安装包，需要从源码构建——毕竟还在快速迭代，装出去的版本一天一个样。
