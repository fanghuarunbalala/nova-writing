# 穿越流总纲（示例书《观潮者》·卷一线）

> 说明：本总纲为卷一线前 6 幕骨架，非全书完整总纲；悬念的"埋/揭/汇"位置均指卷一范围内的排布。

- **故事核心**：一名现代气象观测员雷暴夜穿越成异世渔村少年，在"弄清自己为何而来"与"在潮天世界活下去"的双重压力下，以现代气象知识预判潮汛安身，借识海灯塔联结贵女与海客结成暗盟，逐步揭开潮脉枯竭、司内旧案与吞潮会祭潮背后的真相。

- **长线悬念体系**：
  - **主线悬念（穿越与归途之谜）**：埋（第一幕·雷暴夜穿越与观潮式）→ 升（第二幕·灯塔与潮纹境界联动，归途渺茫）→ 转（第四幕·潮灾中发现灯塔与潮脉同源）→ 汇（第六幕·归途与补脉合为同一答案）。
  - **事件悬念（旧案与司内内鬼）**：埋（第二幕·潮档库抽页、失踪的大测潮官）→ 升（第三幕·内鬼引吞潮会入司）→ 揭（第四幕·潮灾中内鬼现形、司正旧怨曝光）→ 收（第五幕·潮盟共审、旧案定谳）。
  - **力量线（潮纹五境）**：入（第二幕·听潮境初成）→ 展（第三幕·观潮境与潮眼共鸣）→ 升（第五幕·引潮境与潮盟传法）→ 汇（第六幕·御潮境决战）。

- **幕结构总览**（幕 → 场景两级，场景仅列核心事件）：
## 第一幕·异乡观潮
- **梗概**：气象观测员沈观穿越成渔村少年；排查原身遗留的观潮手记与大潮倒计时；市集见识潮纹与听潮司；夜里重演观潮式被卷入识海灯塔，联结贵女云照夜与海客潮生，自称"守灯人"；大潮压境报出风暴转向救下全村，被听潮司测潮官云潮生注意。
- **场景**：
  - 雷暴夜醒来——沈观剧痛醒来确认穿越，发现观潮手记与墙上倒计时刻痕，决定重演观潮式寻归途。
  - 手记与倒计时——通读手记拼出原身观潮七日、出海失踪，锁定"潮眼在东北"与倒计时指向转向潮。
  - 兄妹与生计——妹妹沈萤醒来，兄妹补网话生计，展现贫寒家庭温暖与紧迫。
  - 市集与潮纹——赶集途经盐田鱼市，被卖假潮纹护符的行脚商搭讪，见识潮纹与听潮司背景。
  - 观潮式与识海灯塔——重演观潮式被拉入识海，触碰灯塔灯芯，联结云照夜与潮生。
  - 灯塔初会·守灯人——稳住守灯人形象，促成潮玉换引潮诀交易，三人约定灯塔聚会。
  - 潮汛转向——报出风暴转向救村，云潮生循迹而来；云照夜察觉灯芯印、潮生海船遇吞潮兽。

## 第二幕·听潮入门
- **梗概**：云潮生考校报潮之能递出见习名额；沈观经兄妹夜谈决意入司；入司见识测潮台、潮档库与潮纹五境；灯塔二聚拼出同一场大潮；潮档库发现三十年前潮页被抽的疑云；转正考预判转向潮立功转正，凝纹入听潮境；东北海面祭潮船队悄然集结。
- **场景**：
  - 考校与邀请——云潮生以潮档考校，沈观复盘三次转向潮全中，获见习名额暂缓答复。
  - 兄妹夜谈——沈观以学手艺为说辞，沈萤交出亡父手记残页，沈观决意入司。
  - 入司第一日——领腰牌手账，参观测潮台潮档库，司正讲潮纹五境与考核规矩。
  - 灯塔二聚·情报互换——潮生报吞潮兽异动，云照夜换得引潮诀，三人拼出同一场大潮。
  - 潮档库疑云——三十年前转向潮档案潮页被抽、封签完好，牵出大测潮官失踪旧案。
  - 转正考·预判转向潮——众人依旧档失手，沈观报二次转向救分院，破格转正。
  - 听潮境·潮纹初成——转正夜凝纹入听潮境，灯塔灯火骤亮；祭潮船队集结、潮眼正对渔村。

## 第三幕·潮眼探查
- **梗概**：司正派队探查东北潮眼，沈观以观潮境共鸣锁定潮眼方位；探查船队遭吞潮会伏击，沈观以预判救队立功晋升观潮境；归司后发现探查情报泄露，司内内鬼疑云坐实；灯塔三聚三人共享各自线索，云照夜发现家族藏书与祭潮仪式的关联。
- **场景**：
  - 探查令与组队——司正颁探查令，沈观入队，云潮生领队，同队见习各怀心思。
  - 海上初遇吞潮兽——船队外海遇吞潮兽群，沈观以潮鸣预判兽群动向避战。
  - 伏击与预判——吞潮会伏击探查船队，沈观报出退路窗口救队，晋升观潮境。
  - 泄露之谜——探查路线仅司内数人知晓，沈观比对出入档锁定泄密范围。
  - 灯塔三聚·线索交汇——三人共享祭潮、藏书、海路三线情报，拼出吞潮会"引潮眼北移"的意图。
  - 潮眼共鸣——沈观独自登测潮台与潮眼共鸣，首次"看见"潮脉走向，察觉脉象衰弱。

## 第四幕·潮灾守城
- **梗概**：祭潮引发大潮改道直扑潮汐分院所在的港城；司内内鬼破坏测潮台致全城预警瘫痪；沈观以现代气象知识重建预警、组织守城，内鬼于潮头现形被云潮生拿下；潮灾中沈观发现灯塔灯火与潮脉同源，司正吐露与失踪大测潮官的旧怨。
- **场景**：
  - 大潮改道——祭潮生效，潮眼北移，大潮直扑港城，预警时间不足一日。
  - 测潮台之毁——内鬼破坏测潮台主仪，全城预警瘫痪，人心浮动。
  - 重建预警——沈观以气压、潮鸣与物候重建土法预警网，分区示警。
  - 守城之战——潮头压城，听潮司与民夫依预警布防，沈观报出三个避险窗口。
  - 内鬼现形——内鬼于潮头再度出手被云潮生擒下，供出吞潮会祭司与司内旧怨。
  - 灯塔与潮脉同源——潮灾余烬中灯塔灯火骤明，沈观窥见潮脉如河、脉象枯竭；司正夜谈旧怨。

## 第五幕·潮盟集结
- **梗概**：潮灾后听潮司威信受损，沈观倡议以灯塔为盟联结各方；云照夜以家族名义召集滨海世家，潮生整合海路船帮，潮盟初成；潮盟共审内鬼牵出吞潮会祭司真身；沈观引潮境初成，将"观潮补脉"之法传于盟内；吞潮会主力浮出水面，决战在即。
- **场景**：
  - 灯塔立盟——沈观于识海立潮盟之议，三人各执一灯分领陆、家、海三线。
  - 世家会盟——云照夜以藏书与潮档为证，说动滨海世家共担补脉之资。
  - 海路归心——潮生以吞潮兽航线为筹码，收拢船帮共守海路。
  - 共审内鬼——潮盟会审，内鬼供出祭司以"潮眼北移"献祭求长生的图谋。
  - 引潮境·传法——沈观凝引潮纹，将观潮补脉之法传于盟内测潮员，各地脉象渐稳。
  - 决战前夜——吞潮会祭司现身港外祭潮船队，潮眼异动，灯塔灯火彻夜不熄。

## 第六幕·潮尽灯明
- **梗概**：祭司以潮眼献祭引发潮脉崩解，大潮吞天；沈观御潮境初成，率潮盟于潮眼决战；云照夜以家族潮玉封祭坛、潮生以船队断海路、云潮生正面破祭司；沈观入潮眼以灯塔灯火引归潮脉，潮尽灯明；卷末：归途与补脉合为同一答案，沈观选择留守，灯塔灯火为往来者长明。
- **场景**：
  - 潮眼崩解——祭司献祭生效，潮脉崩解、大潮吞天，各地脉象告急。
  - 御潮境初成——沈观于灯塔灯火中凝御潮纹，灯火与潮脉共鸣，率潮盟赴潮眼。
  - 三路合围——云照夜封祭坛、潮生断海路、云潮生破祭司护法，决战三路并进。
  - 潮眼之战——沈观正面战祭司，以预判拆解祭潮节律，司正旧怨于阵前了结。
  - 引归潮脉——沈观入潮眼，以守灯人之印引灯塔灯火补脉，潮尽而灯明。
  - 卷末·守灯人——潮脉渐复，归途之门一闪而逝，沈观选择留守；灯塔灯火为往来者长明。

- **主线与支线布局**：
  - **主线（生存与成长）**：报潮安身 → 听潮司测潮员 → 潮纹修行 → 潮盟守灯人。
  - **支线一（灯塔暗盟）**：联结（第一幕）→ 情报交易（第二至三幕）→ 潮盟立盟（第五幕）→ 决战中枢（第六幕）。
  - **支线二（旧案与内鬼）**：疑云（第二幕）→ 泄露（第三幕）→ 现形（第四幕）→ 定谳（第五幕）。
  - **支线三（家庭）**：兄妹渔村线贯穿，提供"潮天世界之外的生活"底色与主角行动的情感代价。
  - **支线四（贵女与海客）**：云照夜家族线（藏书→世家会盟）、潮生海路线（船帮→海路合围），各自独立成长并于决战汇流。

- **跨幕情绪曲线**：异乡惊惶中的求生暖意 → 入门的谨慎与志气 → 探查中的步步惊心 → 潮灾的压迫与绝地反击 → 立盟的昂扬与暗流 → 决战的惨烈与灯明的余韵；锚点为"以凡人之知测天意之潮"，每幕围绕锚点微调。

- **与幕设计的接口**：总纲只立幕骨架与悬念排布，场景级细节（事件序列/节奏拍/状态变更）由幕设计任务产出；幕设计细化时只允许加密排布，不允许移动悬念回收位置。
