# 案例大纲细化设计

## 委派需求（示例）

> 把 S5「灯塔初会·守灯人」细化为下一层子故事：保持神秘感递进，结尾落到主角第一次主动以假身份示人。

## 参考产出（示例）

**子故事拆分**（每个子故事一句话核心事件 + 情绪走向）：

- S5.1 核心事件：主角在识海灯塔稳住守灯人形象，两名访客各自试探其来历，他以模糊话术搪塞。情绪走向：紧张 → 强撑镇定。
- S5.2 核心事件：海客讲出潮纹五境与听潮司体系，贵女抛出家族藏书中的孤证与之相悖，主角借“灯下见真”的由头让二人各自举证。情绪走向：好奇 → 角力兴奋。
- S5.3 核心事件：为促成潮玉换引潮诀的交易并保住自己“守灯人”的神秘位格，主角报出一个编造的来历——自称历代守灯人的末位传人。情绪走向：权衡 → 决然（第一次主动以假身份示人，落在情绪锚点上）。

**串联检查**（四选一以上成立即可）：

- S5.1 → S5.2：因果（身份试探未破，才敢进入知识交锋）。
- S5.2 → S5.3：目标递进（从“维持形象”推进到“借形象促成交易”）。
- 情绪曲线：紧张 → 镇定 → 好奇 → 兴奋 → 权衡 → 决然，无连续同强度。

**叶子要素补全**（S5.3 为例，拆到不可再分后逐项补）：

- 时间：首次识海聚会末段；地点：识海灯塔·灯室。
- 出场人物与动机：主角（动机＝守住守灯人位格以维系聚会主导权）、贵女（动机＝验证守灯人是否值得托付家族秘密）、海客（动机＝借交易换取自保之力）。
- 状态变更：主角对外来历由“未知”变“编造的末位传人”；三人关系由“萍水相逢”变“交易绑定的同盟雏形”。
- 悬念钩子：真正的历代守灯人是否存在，留待上层故事回收。

## 要点清单（对照规范段标题，不复述条文）

- 对照「大纲规范」检查：事件序列完整、节奏拍分布、状态变更明确、时间地点可追溯。
- 对照「吸引人的故事」检查：情绪曲线无连续 3 个同强度、每个子故事有独立情绪转折。
- 不超范围：只细化被指定的故事，不擅自改兄弟故事或上层结构。
