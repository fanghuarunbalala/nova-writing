# 案例正文撰写

## 委派需求（示例）

> 撰写 S5.3 的正文草稿：灯塔灯室对话，情绪从权衡到决然，结尾落在主角报出编造来历的瞬间。

## 参考产出（示例）

```novel
灯室里很静，静得只剩潮鸣。沈观把手按在灯芯上，光从指缝里透出来，把他的手背映成淡红色。

"守灯人，"贵女忽然开口，声音里还带着宅邸养出来的软，"我家的藏书里有一页旧潮书。上面写，守灯人历代都有，最后一位死在三百年前的大潮里。"

潮鸣响了一声。

沈观没有把手收回来。他想过一百种说法——识海的雾、雷暴夜、少年额角的潮纹。没有一种能说出口。

"旧潮书是旧潮书。"他说，"我在，是我在。"

"那你是谁？"

灯在他掌心里晃了一下。灯室外，海客还在等交易的答案；贵女的眼睛很干净，干净得让人不敢用真话敷衍，也不配用真话敷衍。

"历代守灯人的末位传人。"沈观听见自己说，"灯没有灭。它在等一个人，等了三百年。"
```

**写法说明**：

- 情绪走位：权衡（手按灯芯不动、"他想过一百种说法"）→ 拉扯（真话不能说、也不配敷衍的两难）→ 决然（谎话以最郑重的形式说出口）——按设计曲线落点，结尾停在谎话说出的瞬间，不写 aftermath。
- 视角纪律：全程贴主角感知，贵女与海客的心理只用可观察行为呈现（开口追问、灯室外等待）。
- 节奏：短句收情绪（"潮鸣响了一声。"），长句放环境与权衡；对话不加"她追问道"式标注，情绪藏在动作与光的反应里。
- 状态变更落笔：主角对外来历的变化用"末位传人""等了三百年"两句完成，不点破这是谎言。

## 要点清单（对照规范段标题，不复述条文）

- 对照「正文规范」检查：视角一致、对话自然、无说明文腔、无赘词。
- 对照「吸引人的故事」检查：情绪是否按要素设计的走向落点、结尾是否停在情绪锚上。
- 人设一致：主角言行符合其性格与动机，不为剧情需要临时变性格。
