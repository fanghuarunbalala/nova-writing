# 案例开头大纲细化设计

## 委派需求（示例）

> 设计全书开篇的大纲：第一卷前几个故事要立住世界观钩子、主角初始欲望，并埋下第一个长线悬念。

## 参考产出（示例）

**开篇三件事的排布**（顺序即信息释放顺序）：

1. 世界观钩子：开篇第一个场景即展示"记忆可以交易"的世界规则——用一个具体交易场面呈现，不用说明文交代。
2. 主角初始欲望：主角想要赎回亡妻的一段记忆——欲望具体、可失败、与世界观规则直接相关。
3. 第一个长线悬念：主角发现自己收到的记忆片段里有一段"不该存在的画面"——只抛出，不在开篇解答。

**信息释放节奏**：

- 每个场景只释放一条世界观规则，用冲突场面带出，禁止设定倾泻。
- 配角入场即带功能（示范规则/制造障碍/映照主角欲望），不为热闹加人。
- 开篇情绪锚点：压抑中带一点执拗的暖——后续所有开篇场景的情绪都围绕这个锚点微调。

**与后续结构的接口**：

- 初始欲望的达成条件在后文被逐步加码（代价递增），开篇只立条件不改条件。
- 长线悬念的回收位置标注到卷级（本卷埋、下卷揭），不承诺本章回收。

## 要点清单（对照规范段标题，不复述条文）

- 对照「故事吸引力」检查：开篇三件事是否各自成立、悬念是否只抛不揭。
- 对照「大纲规范」检查：每个故事的事件序列与状态变更是否支撑上述排布。
- 不预埋：不在开篇为远期剧情堆设定，只落当前需要的最小信息量。
