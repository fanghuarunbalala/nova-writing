对话流 × 工具使用 —— 最终方案

样式：气泡流（用户右气泡 / AI 左卡片）。结构：一个 turn（一次 API 请求）= 内容片段 + 单行工具（该请求调用的所有工具拼在一行，· 分隔）。 命名：进行中 动作+对象+中：内容（如 编辑角色中：张三）· 完成 对象+动作+已完成：内容（如 角色编辑已完成：张三）· 失败 对象+动作+失败：内容； 进行中带 spinner + 秒数脉动，完成/失败带定格耗时。
