# 案例正文撰写

## 委派需求（示例）

> 撰写 S3.3 的正文草稿：天台对话，情绪从挣扎到决然，结尾落在主角说出谎话的瞬间。

## 参考产出（示例）

```novel
雨停了半小时，天台的积水还没退干净。陈默把烟摁灭在栏杆上，听见身后的脚步声，没有回头。

"物证科说你昨晚调过卷宗。"周砚的声音很平，"三点档案库的监控坏了，巧不巧？"

陈默看着楼下的车流。他想过一百种说法，最后说出口的是最简单的那种："查别的案子，顺路。"

"哪个案子？"

"保密。"他转过身，笑了一下，"老周，你什么时候开始审查我了？"

周砚盯着他看了很久。积水里晃着两个人影，一个站得笔直，一个微微发抖——发抖的那个看不出来是在笑。
```

**写法说明**：

- 情绪走位：挣扎（摁烟、不回头）→ 拉扯（想过一百种说法）→ 决然（说出口的是最简单的那种）——按设计曲线落点，结尾停在谎话说出的瞬间，不写 aftermath。
- 视角纪律：全程贴主角感知，搭档的心理只用可观察行为呈现（盯着看了很久）。
- 节奏：短句收情绪，长句放环境；对话不加"他愤怒地说"式标注，情绪藏在动作里。
- 状态变更落笔：信任关系的变化用"审查我"与"保密"两个词完成，不点破。

## 要点清单（对照规范段标题，不复述条文）

- 对照「正文规范」检查：视角一致、对话自然、无说明文腔、无赘词。
- 对照「故事吸引力」检查：情绪是否按要素设计的走向落点、结尾是否停在情绪锚上。
- 人设一致：主角言行符合其性格与动机，不为剧情需要临时变性格。
- 正文用 ```novel 代码块包裹，说明文字留在块外。
