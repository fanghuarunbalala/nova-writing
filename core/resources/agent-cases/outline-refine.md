# 案例大纲细化设计

## 委派需求（示例）

> 把 S3「雨夜追凶」细化为下一层子故事：保持悬念递进，结尾落到主角第一次主动撒谎。

## 参考产出（示例）

**子故事拆分**（每个子故事一句话核心事件 + 情绪走向）：

- S3.1 核心事件：主角循线索潜入旧档案馆，发现卷宗被人为抽页。情绪走向：好奇 → 隐隐不安。
- S3.2 核心事件：档案管理员的证词与物证矛盾，主角意识到内部有人动手脚。情绪走向：不安 → 警觉。
- S3.3 核心事件：为争取查案时间，主角向搭档隐瞒了关键物证。情绪走向：挣扎 → 决然（第一次主动撒谎，落在情绪锚点上）。

**串联检查**（四选一以上成立即可）：

- S3.1 → S3.2：因果（抽页的物证引出矛盾证词）。
- S3.2 → S3.3：目标递进（从"查明真相"推进到"保住查案资格"）。
- 情绪曲线：好奇 → 不安 → 警觉 → 挣扎 → 决然，无连续同强度。

**叶子要素补全**（S3.3 为例，拆到不可再分后逐项补）：

- 时间：雨夜后第三天清晨；地点：队部天台。
- 出场人物与动机：主角（隐瞒动机＝不信任上级）、搭档（被蒙在鼓里）。
- 状态变更：主角对搭档的信任关系由"完全坦诚"变"有保留"；物证下落由"在档"变"私藏"。
- 悬念钩子：抽页的人是谁，留待上层故事回收。

## 要点清单（对照规范段标题，不复述条文）

- 对照「大纲规范」检查：事件序列完整、节奏拍分布、状态变更明确、时间地点可追溯。
- 对照「故事吸引力」检查：情绪曲线无连续 3 个同强度、每个子故事有独立情绪转折。
- 不超范围：只细化被指定的故事，不擅自改兄弟故事或上层结构。
