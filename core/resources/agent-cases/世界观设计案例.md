# 穿越流世界观设计案例

## 1. 基础设定

- **时代背景**：潮天世界——天穹之上悬着一层名为"潮层"的灵气之海，它像海水一样涨落流动，天气即潮层的潮汐：潮落则晴朗，潮涨则风雨，潮涌则灾。文明处于"靠潮吃潮"的渔盐时代，测潮术是官方显学，民间以潮祭、潮谚与潮纹护符为俗信。
- **地理概况**：故事始于东南沿海的盐湾渔村，向内陆延伸至听潮司潮汐分院所在的港城；东北海面是潮眼成形、吞潮兽出没的凶险水域；滨海世家盘踞各港口，海路船帮行走外海。
- **文明等级**：渔盐与测潮文明；人类社会中存在以潮纹修行的"潮纹修士"阶层，普通人知其存在而难窥门径。
- **人口规模**：盐湾渔村数百户、港城数万人口；潮纹修士（含听潮司、世家供奉与海路散修）不足百人——修士是极少数。

## 2. 力量体系

- **力量来源**：潮纹与共鸣。一切潮纹之力源于与潮层的共鸣——修士感应潮鸣、在体内凝出潮纹，潮纹即境界；潮层既是力量之源，也是灾厄之源，修行与天灾同源。
- **等级划分**：潮纹五境——听潮（感应潮鸣）→ 观潮（测潮报汛）→ 引潮（引动局部潮势）→ 御潮（驾驭潮力攻防）→ 化潮（身与潮合，传说之境）。听潮司测潮员多为听潮、观潮两境，司正与世家供奉可达御潮。
- **获取方式**：感应潮鸣 → 凝纹入听潮 → 逐境凝纹；凝纹需"潮媒"（潮玉、深海兽骨、百年潮档纸灰等），潮媒由听潮司、世家与地下市场流通。
- **使用代价（必须有）**：每一境的代价都刻在能力里——听潮者耳中常有潮鸣幻听，久居静室反成折磨；观潮者越算越准、也越难安眠（潮汛入梦）；引潮以上者动用潮力会引来吞潮兽注视；强行越境共鸣者会被潮层"同化"，化为潮灾的一部分。

## 3. 社会结构

- **权力分配**：表面是官府、盐商与船帮主导沿海生计；暗面是听潮司掌握潮报签发之权——潮报定渔汛、决避潮、掌沿海安危，司内设分院遍布要港；滨海世家以藏书与潮玉供养修士，与听潮司既合作又博弈。
- **阶层流动**：世家子弟有潮媒与藏书的天然优势；平民向上流动靠听潮司的见习考校（报潮有功者可破格）；潮纹修士与平民之间隔着一道"潮墙"——修士的修行细节与潮灾真相，从不写入告示。
- **核心矛盾**：测潮与祭潮的对立（听潮司主张"避潮"，吞潮会主张"吞潮自救"）；世家与官方的暗斗（藏书归属与潮报签发权）；潮脉枯竭的隐忧（近年潮汛越来越凶，有识之士隐约察觉潮层在衰弱，却无人敢公开言说）。

## 4. 历史脉络

- **近百年前：潮脉全盛**——古潮书记载潮脉如河、纵横天下，化潮境的先民以身补脉，留下"守灯人"的传说；如今守灯人只剩民间故事里的一句童谣："潮尽灯明，灯明人归。"
- **数十年前：听潮司立制**——听潮司整合各港测潮术，立潮报签发之制，潮纹五境成为官方定名；同期吞潮会因"吞潮可渡劫"的教义被逐入地下。
- **近十年前：潮汛转凶**——转向潮、回马潮等异常潮汛逐年增多，三十年前一场大转向潮曾吞没三个渔村；主持当年测潮的大测潮官事后失踪，相关潮档被封存——这是盐湾一带老人讳莫如深的旧事。

## 5. 隐藏规则

- **识海灯塔**：极少数人在濒死或大愿之际可"点亮"识海中的灯塔——那是潮层留给守灯人的遗产，能联结散落各地的点灯人；灯塔与潮脉同源，灯火明暗随潮脉盛衰而变化。多数修士终其一生不知道它的存在。
- **潮脉的真相**：潮层不是无穷之水——它靠潮脉从大地汲取生机；吞潮会以祭潮"喂"潮眼，实则在透支潮脉。潮脉枯竭之日，即潮层坠落之时。
- **吞潮兽的来历**：吞潮兽并非天生怪物——它们是历代被潮层同化的修士与生灵的残形，循潮鸣而动，见潮纹修士如见归途。猎杀吞潮兽的修士若知其来历，往往会迟疑一瞬——这一瞬常常致命。

## 6. 日常细节

- **出行与照明**：渔船与盐道是生计命脉，港城以潮油灯照明（潮兽脂熬制，风里不熄）；潮汛季封海，商队改走内陆盐道。
- **通信与信息**：潮报以潮旗与潮锣逐级传递，听潮司的潮报台是沿海最高的建筑；民间以潮谚记潮（"盐潮出水，三日有风"），渔村孩童能背整本《潮谚集》。
- **娱乐与信仰**：潮祭是沿海最隆重的节庆，各村以盐雕供潮；潮纹护符、假潮玉与"观潮式"占卜在市集流行——普通人排队求一枚护符，修士在同一个街区交易真正的潮媒；行脚商穿梭其间，真假混卖。
