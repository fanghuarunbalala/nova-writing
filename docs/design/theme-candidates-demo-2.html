调色板（语义色 token）
实现方式（与本 demo 同构）：tokens.css 追加 [data-theme] 覆盖块（只含 --color-* / --shadow-*，纪律测试规则 b 自动执法）； ThemeProvider 扩展主题枚举并挂载到 NovelApp 根；设置弹窗新增「外观」分类（主题卡片 + 图标）；选择持久化 localStorage； 切换时挂 html.theming 类做 0.35s 全局颜色过渡。暗色主题额外覆盖 --color-on-accent 为深墨色（强调底提亮后白字对比度不足）。 新增五套（竹雨/鎏金/胭脂/紫檀/烛影）配色取自用户罗列的传统色，派生色（加深/提亮/染底）已在 CSS 注释中标注来源。 审批面板切片：操作色带（增=success / 删·编辑=danger）与状态 pill 全部走语义 token，随主题自动换色； 动画提案（appr-in 入列 / 状态脉冲 / 请求修改 0fr→1fr / 详情 view-in / 计数弹跳）实施时并入 animations.css。 实施时顺带修两个现网问题：① ApprovalPanel 请求修改输入框用了 legacy hex token（--color-bg-elevated #1e1e24 / --color-text #ddd）， 亮色主题下渲染为暗底白字，应换 --color-surface / --color-fg；② 已修改（edited）状态 pill 无配色（裸样式），建议补 info 色。
